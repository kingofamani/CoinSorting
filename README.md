# 智能自動分幣機（教師研習創客專案）

雷切機構分幣機：TT 馬達帶轉盤，把 1、5、10、50 元硬幣送上斜坡，依直徑落進 4 個抽屜。
目標是加上感測器自動計算總金額，用七段顯示器顯示。

**開新對話先看：** [`分幣機_交接_2026-10-08.md`](分幣機_交接_2026-10-08.md) 和 [`分幣機_專案完整紀錄v2.txt`](分幣機_專案完整紀錄v2.txt)（第五節最新）。

## 怎麼重新產生

Python 環境在根目錄的 `.venv`（不在 git 裡；已裝 shapely、numpy、scipy、matplotlib、fonttools、svgpathtools）。

```
cd 03_v2_光耦版
../.venv/Scripts/python.exe -B -m laser_v2.build_v2
```

```
.venv/Scripts/python.exe -B 04_光耦測試原型/make_proto.py
```

- v2：光耦模組、TM1637、擴展板實量後只改 `03_v2_光耦版/laser_v2/params.py`，量什麼、改哪個鍵見 `laser_v2/out/report.md` 第四節。
- 測試原型：模組實量後改 `make_proto.py` 開頭的 `MODULE`，見 `04_光耦測試原型/組裝與測試說明.md` 第 2 節。
- 字型：雕刻文字與預覽圖用微軟正黑體（`C:\Windows\Fonts\msjh.ttc`）。
- 各檔用途、結束碼、自我測試：見 `03_v2_光耦版/laser_v2/INTERFACE.md` 與專案紀錄第五節。

## 硬體（v2）

- 主控：ESP32-WROOM-32＋38P 擴展板（黃色跳帽設 3.3V）；顯示：TM1637 四位數七段。
- 感測：槽型 LM393 光耦模組（槽寬 10 mm）×4：S1 在 1 元滑道內，S5／S10／S50 跨在斜坡間隔條。
- 電源：9V 方形電池供電子部分；1 顆 18650 獨立驅動 TT 馬達。
- 計數公式：N1＝C1、N5＝C5−C10、N10＝C10−C50、N50＝C50。
- 程式：`03_v2_光耦版/coin_sorter_opto_esp32/`（接線、燒錄、研習前檢查見同資料夾 README.md；還沒在實機編譯、執行過）。
- 接線圖：`03_v2_光耦版/接線圖/分幣機_v2光耦版_ESP32_接線圖.png`（.svg 由同資料夾 make_wiring.py 產生）。
