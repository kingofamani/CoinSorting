# 分幣機 v2（光耦版）ESP32 正式程式

`coin_sorter_opto_esp32.ino`：4 個槽型光耦計數，TM1637 顯示總金額。不需安裝函式庫。

> 這支程式還沒在實機上編譯、執行過（寫的環境沒有 Arduino 編譯器）。第一次編譯如果出錯，把錯誤訊息貼給 Claude。

## 接線

擴展板黃色跳帽設 **3.3V**。光耦模組的 VCC 接 **V 排針（3.3V）**，不要接 5V 排針。

| 感測器 | 位置 | 只有哪些硬幣會經過 | 接到 |
|---|---|---|---|
| S1 | 1 元滑道內 | 1 元 | G27 的 S |
| S5 | 1\|5 間隔條 | 5、10、50 元 | G26 的 S |
| S10 | 5\|10 間隔條 | 10、50 元 | G25 的 S |
| S50 | 10\|50 間隔條 | 50 元 | G33 的 S |
| TM1637 | 正面 #24 左上 | — | CLK→G14、DIO→G13、VCC→V、GND→G |

排線兩端都貼標籤：模組端貼站名（S1／S5／S10／S50），盒端照上表插。

## 計數方式

| 符號 | 意思 |
|---|---|
| C1、C5、C10、C50 | 各感測器擋住的次數（每枚硬幣經過算一次） |
| N1＝C1 | 1 元枚數 |
| N5＝C5−C10 | 5 元枚數 |
| N10＝C10−C50 | 10 元枚數 |
| N50＝C50 | 50 元枚數 |
| 總金額 | C1＋5×C5＋5×C10＋40×C50 |

一定要 C5 ≥ C10 ≥ C50。不成立時顯示器的**冒號（或第 2 位小數點）會亮**，序列埠會印出是哪一站漏算或多算。

## 燒錄

1. Arduino IDE 開 `coin_sorter_opto_esp32.ino`（資料夾名稱要和 .ino 同名，不要改）。
2. 開發板選「ESP32 Dev Module」，連接埠選 CP2102 那個 COM。燒錄時先拔掉 9V 電池。
3. 出現「Connecting……」時按住板上的 **BOOT** 鍵，開始寫入後放開，完成後按 **RST**。
   （永久解法：EN 與 GND 之間接 10µF 電解電容，長腳接 EN。）

## 使用

1. **4 個感測器槽裡清空**再開電源。顯示「1234」約 1.5 秒，這段時間程式會自動判定「擋住時是 HIGH 還是 LOW」。
2. 顯示「0」後再開馬達、倒硬幣。顯示器顯示總金額；每一枚在離開感測器時才加上去。超過 9999 顯示「----」（序列埠有完整金額）。
3. 歸零：**先停馬達、等軌道上沒有硬幣**，再按 **BOOT** 鍵（不重開機）；或按 **RST** 鍵（重開機，會重新判定）。
   軌道上還有硬幣時歸零，之後 C5≥C10≥C50 可能不成立（冒號會亮）。

## 序列埠（115200）

每次計數變動印一行，例如：

```
+ S5+1 S10+1  | C1=3 C5=5 C10=2 C50=1 | 1元×3 5元×3 10元×1 50元×1 | 總額 78 元
```

| 指令 | 作用 |
|---|---|
| `v` | 即時狀態開／關：每 0.2 秒印 4 個感測器（■＝擋住、·＝亮）、腳位電位、計數、擋住次數、校正次數 |
| `r` | 歸零 |
| `a` | 重新判定擋住電位（4 個槽先清空），並歸零 |
| `?` | 說明與目前設定 |

## 可以調的設定（程式開頭「2. 設定」）

| 設定 | 預設 | 什麼時候改 |
|---|---|---|
| `BLOCKED_LEVEL_SETTING` | `LEVEL_AUTO`（開機自動判定） | 自動判定常出錯時，直接寫 `HIGH` 或 `LOW` |
| `REARM_US` | 3000（＝3 ms） | **單位是微秒**。光束要連續亮這麼久，下一次擋住才算新的一枚。丟一枚卻 +2 就調大（例如 5000）；兩枚相貼滾過只算 1 枚就調小。建議用 `04_光耦測試原型/opto_test_esp32` 丟幣測試報告「方法二」的建議值；報告寫 0.5 ms 就填 500 |
| `MIN_BLOCK_US` | 300（＝0.3 ms） | 擋住不到這麼久當雜訊不算。馬達開著、沒有硬幣，用 `v` 看到「擋住次數」自己增加時調大（例如 1000） |
| `BRIGHTNESS` | 4 | 顯示器亮度 0～7 |
| `LONG_BLOCK_MS` | 3000 | 某個感測器連續擋住超過這麼久，序列埠提醒卡幣 |

## 研習前檢查（講師）

1. 開機看序列埠：4 個感測器的「擋住＝」應該一樣，而且沒有「訊號變了 N 次」的警告；顯示器有回應。
2. 輸入 `v`，用名片逐一擋 S1、S5、S10、S50，對應那一欄要從 · 變 ■，其他欄不變（排線插錯會在這裡看出來）。
3. 再輸入 `v` 關掉。手動各丟幾枚：
   - 1 元：只有 C1 +1。
   - 5 元：只有 C5 +1。
   - 10 元：C5、C10 各 +1。
   - 50 元：C5、C10、C50 各 +1。
4. 開馬達倒入已知總額的硬幣，比對顯示金額。

## 常見狀況

| 狀況 | 原因與處理 |
|---|---|
| 某一路完全不計數 | 那一路的訊號線沒接好或插錯腳：用 `v` 擋槽看那一欄會不會變 |
| 沒有硬幣也一直加 | 雜訊或接觸不良：用 `v` 看「擋住次數」；重新插好排線，必要時調大 `MIN_BLOCK_US` |
| 序列埠提醒「連續擋住超過 3 秒」 | 卡幣；或開機時那個槽被擋住，擋住電位判定反了（每過一枚就會出現這個提醒，計數也會慢一枚：第 k 枚要等第 k+1 枚來才加）→ 清空後輸入 `a`；常常判定錯就把 `BLOCKED_LEVEL_SETTING` 改成 `HIGH` 或 `LOW` |
| 丟一枚卻 +2 | 調大 `REARM_US` |
| `v` 裡「校正」一直增加 | 訊號邊緣抖得很厲害或接觸不良（程式會自動校正，但最好檢查排線與模組） |
| 冒號亮 | C5≥C10≥C50 不成立：看序列埠是哪一站。常見是排線插錯（用 `v` 檢查）或模組位置不對 |
| 顯示器不亮 | 檢查 CLK→G14、DIO→G13、VCC、GND；開機序列埠會說顯示器有沒有回應 |
